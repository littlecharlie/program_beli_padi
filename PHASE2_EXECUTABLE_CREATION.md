## Created Files - Detailed Description

### 1. Application Icon

**File:** `resources/app_icon.ico`

- **Generated by:** `create_icon.py`
- **Sizes included:** 256×256, 128×128, 64×64, 48×48, 32×32, 16×16
- **Design:** Green rice grain theme (customizable)
- **Format:** Windows .ico format

**Customizing the Icon:**

To use your own icon:
1. Create a .ico file with multiple sizes (use online converter or Photoshop)
2. Replace `resources/app_icon.ico`
3. Rebuild with `python build_executable.py --clean`

Recommended icon tools:
- IcoFX (Windows)
- GIMP (with ICO plugin)
- Online: convertio.co, favicon.io

### 2. PyInstaller Specification File

**File:** `rice_billing.spec`

This file configures how PyInstaller builds the executable.

**Key Configurations:**

```python
# Application metadata
APP_NAME = 'RiceBillingSystem'
VERSION = '1.0.0'
COMPANY_NAME = 'AYOP BIN ARSHAD'

# Icon
icon_path = 'resources/app_icon.ico'

# Data files to include
datas = [
    ('printing/templates/*.txt', 'printing/templates'),
    ('resources/app_icon.ico', 'resources'),
]

# Hidden imports (packages not auto-detected)
hiddenimports = [
    'PyQt5', 'psycopg2', 'sqlalchemy',
    'reportlab', 'escpos', 'win32print', ...
]
```

**Build Modes:**

The spec file is configured for **ONE-FOLDER** mode by default:
- **Pros:** Faster to build, easier to debug, faster startup
- **Cons:** Multiple files (exe + _internal folder)

To use **ONE-FILE** mode:
1. Open `rice_billing.spec`
2. Comment out the ONE-FOLDER section (lines with `COLLECT`)
3. Uncomment the ONE-FILE section (commented `exe = EXE(...)`)
4. Rebuild

**One-file vs One-folder:**

| Feature | One-Folder | One-File |
|---------|-----------|----------|
| Number of files | Many (exe + folder) | Single .exe |
| Startup speed | Fast | Slower (extracts to temp) |
| Size | Same (~150-200 MB) | Same |
| Debugging | Easier | Harder |
| Distribution | Need zip | Just .exe |
| **Recommendation** | ✅ Development & Testing | ⚠️ Final release (optional) |

## Common Build Issues & Solutions

### Issue 1: PyInstaller Not Found

**Error:** `pyinstaller: command not found`

**Solution:**
```bash
pip install pyinstaller==5.13.2
```

### Issue 2: Icon File Not Found

**Error:** `Icon file not found: resources/app_icon.ico`

**Solution:**
```bash
python create_icon.py
```

### Issue 3: Missing Templates in Build

**Error:** Templates not found at runtime

**Solution:**
- Check `rice_billing.spec` includes template files
- Verify `printing/templates/*.txt` exists
- Rebuild with `--clean` flag

### Issue 4: Module Not Found at Runtime

**Error:** `ModuleNotFoundError: No module named 'X'`

**Solution:**
- Add module to `hiddenimports` in `rice_billing.spec`
- Common missing modules: `sqlalchemy.dialects.postgresql`, `win32print`
- Rebuild after adding

### Issue 5: Build Takes Too Long

**Cause:** PyInstaller analyzing all dependencies

**Solutions:**
- Use `--clean` only when needed
- Exclude unnecessary modules in spec file
- First build is slowest (~5-10 minutes)
- Subsequent builds faster (~2-3 minutes)

### Issue 6: Executable Too Large

**Current size:** ~150-200 MB (expected for PyQt5 + PostgreSQL app)

**To reduce size:**
- Use UPX compression (already enabled in spec)
- Exclude unused modules (check `excludes` in spec)
- Consider SQLite instead of PostgreSQL (smaller)
- Note: Cannot reduce much below 100 MB due to PyQt5

## Advanced Configuration

### Custom Version Information

To add version info to executable (shows in Windows properties):

1. Create `version_info.txt`:
   ```python
   VSVersionInfo(
     ffi=FixedFileInfo(
       filevers=(1, 0, 0, 0),
       prodvers=(1, 0, 0, 0),
       ...
     ),
     StringFileInfo(...),
     ...
   )
   ```

2. Update spec file:
   ```python
   version_file='version_info.txt'
   ```

3. Rebuild

### Digital Signature (Optional)

For production release:

1. Obtain code signing certificate
2. Sign executable with SignTool (Windows SDK)
3. Prevents "Unknown Publisher" warnings

```bash
signtool sign /f certificate.pfx /p password RiceBillingSystem.exe
```

### UPX Compression

Already enabled in spec file (`upx=True`).

To disable (larger file, faster startup):
```python
upx=False
```

## Troubleshooting Runtime Issues

### Application Won't Start

**Symptoms:** Double-click does nothing, or crashes immediately

**Solutions:**
1. Run from command line to see errors
2. Check Windows Event Viewer → Application logs
3. Ensure .NET Framework 4.5+ installed (for pywin32)
4. Test in demo mode first

### Database Connection Fails

**Symptoms:** "Cannot connect to database" error

**Solutions:**
1. Verify PostgreSQL service running
2. Check .env file configuration
3. Test connection with pgAdmin
4. Check firewall settings
5. Verify database exists

### Printer Not Found

**Symptoms:** "Printer not detected" or print fails

**Solutions:**
1. Install Epson LQ-310 driver
2. Check USB connection
3. Set printer as default
4. Verify printer name in .env matches Windows name
5. Check printer is powered on
